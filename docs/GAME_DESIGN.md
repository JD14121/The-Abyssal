# Game Design

## Project Vision

Create a hardcore survival simulation game focused on emergent systemic gameplay.

The player should survive primarily through understanding interconnected systems rather than following a linear progression.

## Design References

Primary architectural references:

- CDDA: data-driven content and simulation depth
- Project Zomboid: real-time interaction and survival gameplay

These projects are references only.

Final gameplay, setting, assets, balance, writing, map content, and implementation should be original.

## Core Gameplay Loop

Explore
-> Search
-> Acquire Resources
-> Manage Survival Needs
-> Avoid or Fight Threats
-> Recover
-> Improve Preparedness
-> Explore Further

## Design Priorities

1. System interaction
2. Player decision making
3. Resource scarcity
4. Persistent consequences
5. Replayability
6. Expandable content architecture

## Initial MVP

The first playable version should eventually contain:

- player movement
- small test map
- interaction system
- containers
- inventory
- food and water
- hunger and thirst
- basic health
- zombies
- basic perception
- melee combat
- loot
- death
- save/load

## Explicitly Out of Initial Scope

- multiplayer
- vehicles
- NPC societies
- advanced farming
- full electricity simulation
- advanced fire propagation
- massive procedural world
